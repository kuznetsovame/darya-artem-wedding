Сайт Дарьи и Артёма — RSVP подключён к Google Apps Script.

ВАЖНО: 1) Замените содержимое Код.gs текстом из GOOGLE_APPS_SCRIPT.txt. 2) Сохраните. 3) Развернуть → Управление развёртываниями → Изменить (карандаш) → Версия: Новая версия → Развернуть. 4) Загрузите файлы сайта на GitHub Pages. 5) Отправьте тестовую анкету и проверьте таблицу и Telegram.

Особенность: браузер GitHub Pages не может прочитать ответ Apps Script (CORS), поэтому сообщение на сайте подтверждает отправку запроса, но не гарантирует запись в таблицу. Проверяйте первую отправку в таблице.
